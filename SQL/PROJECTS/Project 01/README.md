# 📊 Raw Dataset SQL Analysis

## 📌 Project Overview

This project is part of my **SQL Learning Journey**, where I am developing practical SQL and PostgreSQL skills by working with real datasets.

The project begins with a **raw dataset imported into PostgreSQL**. The objective is to explore the data, understand its structure, identify potential data-quality issues, and use SQL queries to extract meaningful insights.

Rather than immediately transforming the dataset, I am keeping the original raw data intact and using SQL to understand what is actually contained within it.

## 🎯 Project Objectives

The main objectives of this project are to:

* Import and work with a raw dataset in PostgreSQL

## 🔍 Project Workflow

The analysis follows a step-by-step process:

### 1. Data Import

The raw dataset was imported into PostgreSQL and stored as a database table.

### 2. Data Exploration

Initial queries are used to understand:

* Number of records
* Number of columns
* Column names
* Data types
* Distinct values
* General patterns within the dataset

### 3. Data Quality Checks

The dataset will be checked for:

* Missing values
* Duplicate records
* Inconsistent values
* Unexpected data types
* Outliers or unusual records
* Formatting inconsistencies

### 4. Data Analysis

SQL queries will then be used to investigate patterns and answer analytical questions using techniques such as:

* `SELECT`
* `WHERE`
* `ORDER BY`
* `GROUP BY`
* Aggregate functions
* `CASE`
* `JOIN`
* Subqueries
* CTEs
* Window functions

### 5. Insights & Findings

The final stage will document the key insights discovered through the analysis and explain how SQL was used to arrive at those conclusions.

## 🧠 SQL Concepts Practiced

This project provides an opportunity to practice and strengthen:

| SQL Concept       | Purpose                                  |
| ----------------- | ---------------------------------------- |
| `SELECT`          | Retrieve data                            |
| `WHERE`           | Filter records                           |
| `ORDER BY`        | Sort results                             |
| `DISTINCT`        | Identify unique values                   |
| `COUNT()`         | Count records                            |
| `SUM()`           | Calculate totals                         |
| `AVG()`           | Calculate averages                       |
| `MIN()` / `MAX()` | Identify minimum and maximum values      |
| `GROUP BY`        | Analyse groups of data                   |
| `CASE`            | Create conditional logic                 |
| `JOIN`            | Combine related tables                   |
| CTEs              | Break complex queries into logical steps |
| Window Functions  | Perform advanced analysis                |
